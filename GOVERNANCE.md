# 🏛️ Open Source Governance Model

FileX operates as a transparent, community-oriented open-source project. Our governance framework ensures fair code reviews, structural decisions, and maintainer promotions.

---

## 1. Roles and Responsibilities

* **Users:** Anyone running FileX agents locally or deploying monitored pipelines in production.
* **Contributors:** Individuals who submit code commits, bug fixes, or documentation updates via pull requests.
* **Maintainers:** Core decision-makers with write access to the main branch. They direct PR reviews, approve releases, and oversee security patches.

---

## 2. Decision Making Process

Our goal is to achieve architectural consensus on all system changes:
* **Minor Actions (e.g. Bug Fixes, Docs):** Require approval from at least **one Maintainer**.
* **Major Changes (e.g. Database Migrations, EventBus Overhauls):** Require review and approval from at least **two Maintainers** to guarantee API backward compatibility.

---

## 3. Maintainer Promotion Lifecycle

Contributors who demonstrate sustained commitment, constructive code reviews, and deep architectural understanding over a **6-month period** may be nominated by an existing maintainer to join the core team.
